RogbaDox Favicon Package

Files:
- favicon.ico: multi-resolution browser favicon
- favicon-16x16.png, favicon-32x32.png, favicon-48x48.png: browser/tab icons
- apple-touch-icon.png: iOS home-screen icon (180x180)
- android-chrome-192x192.png, android-chrome-512x512.png: app/manifest icons
- site.webmanifest: web app icon metadata
- browserconfig.xml: Windows tile metadata
- favicon-html-snippet.html: HTML tags to paste inside <head>

Install:
1. Copy the image and manifest files into your project's public folder.
2. Paste the tags from favicon-html-snippet.html inside the <head> element in index.html.
3. Restart the dev server if needed, then hard-refresh the browser. Favicons may be cached.
